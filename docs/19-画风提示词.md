# 图片生成 · 画风提示词记录与收藏

## 常用画风（自动统计）

- 每次 **成功生成一批**（ComfyUI 或 OpenAI 风格后端均适用）后，OVO会从当次的 **正向提示词** 与 **反向提示词** 中，按逗号、分号、换行拆成 **短语**。
- 同一次生成里，**相同短语只计 1 次**；多次生成会 **累计次数**。
- 右侧面板「常用画风」按次数从高到低展示（最多约 32 条），短语旁显示 **×次数**。
- **点击短语** 会追加到「使用的提示词」末尾（自动加逗号）。
- **清空统计**：只清空次数表，**不会删除**「我的画风收藏」。

短语长度限制约 2～120 字符；本地累计条目过多时会自动删掉次数最低的一批，避免无限膨胀。

## 我的画风收藏

- 填好「使用的提示词」和（可选）「反向提示词」后，点 **「收藏当前为画风」**，输入名称即可保存 **整套** 正/反向提示词。
- **应用**：一键写回两个输入框。
- **删除**：移除该条收藏。

数据保存在浏览器 `localStorage` 的 `ovo_workflow_state` 中（`styleTokenCounts`、`stylePresets`）。

## 与协同 AI 词条的关系

- **AI 推荐词条**：来自讨论区提炼，偏当次创作。
- **常用画风**：来自你实际生成时用过的高频短语，偏长期习惯。
- **画风收藏**：你明确命名的「模板」，适合固定项目风格。
