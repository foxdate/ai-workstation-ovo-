# 图片生成 · 参考图与「根据参考图生成词条」

## 功能

- 在 **左侧栏「参考图」** 中可上传 **最多 2 张** 图片（自动压缩为 JPEG 以节省本地存储）。
- 预览显示在左栏；可 **移除** 单张或 **清空** 全部。
- 在 **协同讨论** 里点 **「发送」或「提炼关键词」** 时，若左侧仍有参考图，会像 **主对话带图片附件** 一样，把当前参考图与输入文字 **一并** 作为该条 `user` 消息发给协同 AI（`content` 为 `text` + `image_url` 数组）。
- 点击 **「根据参考图生成词条」** 时，同样先写入一条带图的用户消息到讨论区，再按 **词条专用 system** 调用协同 AI，输出 `<<<ZHIQUAN_TERMS>>>` 并解析到 **AI 推荐词条**。

## 必要条件

- 协同 AI 必须是 **支持视觉** 的 **API 模型**（通过「API 储存」接入），例如常见多模态聊天模型（各厂商名称不同，需接口兼容 OpenAI `chat/completions` 且支持 `image_url`）。
- **插件协同**、**纯文本模型** 无法读图，会提示错误。

### 通义千问（阿里云 DashScope）

- **Base URL** 请使用兼容 OpenAI 的地址，例如：`https://dashscope.aliyuncs.com/compatible-mode/v1`（末尾可带或不带 `/v1`，与你在「API 储存」里填写一致即可）。
- 需在阿里云 **开通** 对应模型服务，并使用 **VL / 多模态** 模型名（如 `qwen-vl-plus`）。若协同里仍选的是纯文本 `qwen-turbo` 等，本客户端在检测到参考图时会 **自动改用 `qwen-vl-plus`** 发请求（并尽量提示），否则云端无法解析图片。
- 图片以 **Data URL（Base64）** 形式放在 `image_url.url` 中，与官方文档一致。
- 页面拉取 DashScope 的 `/models` 后，**只会列出少量常用兼容型号**（如 `qwen-turbo` / `qwen-plus` / `qwen-max` / `qwen-long` / `qwen-vl-plus` / `qwen-vl-max`），避免控制台返回的上百个 id 占满下拉框；带日期的快照名仍会按原 id 保留（若能匹配到上述基名）。
- 发送请求前会按阿里云兼容接口说明整理 **`messages`**：避免**连续两条 `user`**（例如讨论区最后一条是未回复的纯文本 user、再发带图 user）；多模态条目中 **`text` 在前、`image_url` 在后**；API 地址支持 `dashscope.aliyuncs.com`、`dashscope-intl.aliyuncs.com`、`dashscope-us.aliyuncs.com` 等。

## 与下方输入框的关系

- 有参考图时，输入框可留空再点「发送」：会使用与主对话类似的默认提示（如「请结合当前参考图回答」）并 **仍附带参考图**。
- 「根据参考图生成词条」前可在输入框写补充说明；留空则使用默认提炼说明。讨论区会显示带 📷 的摘要（含图时）。

## ComfyUI 出图时「按参考图画风」

在 **图片生成** 左侧参考图区域下方可勾选 **「ComfyUI 出图时按参考图画风」**：

- **已填写「画风用 LoadImage 节点 ID」**：将把**首张参考图**上传到本机 ComfyUI，并写入该工作流里对应 `LoadImage` 节点（适用于 IP-Adapter、风格参考等；需你在 ComfyUI 中已接好该节点）。
- **未填节点 ID**：在点击「生成一批」时，会先用**协同 AI**（须选支持视觉的 API 模型）从参考图提取**一行英文画风 tag**，与右侧「固定短语·前缀」合并后写入正向提示词，再调用 ComfyUI。

若关闭勾选，则参考图仍会在协同讨论发送时随消息上传，但不会自动参与 ComfyUI 生成。

## 存储与限制

- 参考图以 Base64 存在浏览器 `localStorage`（`zq_workflow_state.refImages`），过大可能触发 **只保留一张** 或 **清除参考图** 的提示。
- 若需长期保存大图，请在本机另存文件，勿依赖浏览器配额。
