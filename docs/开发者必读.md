# 开发者必读：确保本机一定能用

不依赖 pip、Docker，**先搭起来能打开界面**（可不接 API），再按需对接后端。完整安装见 [00-详细安装与使用教程](00-详细安装与使用教程.md)。

---

## 一、先搭起来（仅需 Python，可不接 API）

**目标**：能打开OVO页面，看到多对话、技术亮点、模型下拉框。页面上若提示「未连接 AI 后端，仅可浏览界面」属正常，表示软件已搭好。

**操作：**

1. 安装 **Python** 并勾选 Add to PATH（https://www.python.org/downloads/）。
2. 进入项目目录，双击 **「启动.bat」**，选 **1**（本地网页服务）。
3. 会新开一个服务器窗口，约 3 秒后自动打开浏览器；若未打开，请访问 **http://localhost:8888/** 或 **http://localhost:9000/**。
4. 能看到页面即表示**本机可正常使用**。发消息若提示无法连接，可稍后配置 LiteLLM/Ollama 再试。

**下一步**：对接 AI 见 [01-LiteLLM-启动与挂载](01-LiteLLM-启动与挂载.md)、[06-Ollama-本地免Key](06-Ollama-本地免Key.md)；依赖说明见 [如何安装依赖](如何安装依赖.md)。

---

## 二、可选：要真实 AI 回复

| 方式 | 操作 |
|------|------|
| **LiteLLM（云模型）** | 装 Docker，**「启动.bat」** 选 **3**，页面选模型即可。 |
| **Ollama（本地免 Key）** | 安装 Ollama，执行 `ollama run qwen2:7b`，先启动 Ollama 再启动 LiteLLM，页面选 Ollama 模型。 |

## 三、自检（一条命令）

在项目根目录执行：

```bash
python -c "from server_with_proxy import run_server; print('OK: 可启动')"
```

输出 `OK: 可启动` 即表示环境正常，再运行「启动.bat」选 1 即可。
