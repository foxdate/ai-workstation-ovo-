# OVO - 打包与发布清单

发给别人安装测试时，按本清单打压缩包，可保证对方在**无环境基础**的电脑上按文档完成安装。

---

## 一、压缩包内应包含的文件/文件夹

打 zip 时，**只打包项目根目录下的这些内容**（保持相对路径）：

| 类型 | 路径 | 说明 |
|------|------|------|
| 必选 | `请先读我.txt` | 解压后第一眼看到的说明，引导阅读安装指引 |
| 必选 | `index.html` | 主界面 |
| 必选 | `highlights.html` | 技术亮点页 |
| 必选 | `server_with_proxy.py` | 本地服务与 API 代理 |
| 必选 | `desktop_app.py` | 桌面版入口 |
| 必选 | `检查安装.py` | 自检脚本 |
| 必选 | `检查安装.bat` | 自检；末尾可按提示安装 pywebview（可选） |
| 必选 | `启动.bat` | 菜单：1 网页 / 2 桌面 / 3 LiteLLM / 4 打包 exe |
| 必选 | `requirements-desktop.txt` | 桌面版 pip 依赖列表 |
| 必选 | `litellm/` | 整个文件夹，内含 `config.yaml` |
| 必选 | `docs/` | 整个文件夹，所有 .md 文档 |
| 必选 | `scripts/` | 整个文件夹（若有） |
| 必选 | `memory_store/` | 整个文件夹（若有） |
| 必选 | `README.md` | 项目说明 |
| 必选 | `首次安装指引.md` | 零基础安装步骤（根目录） |

**说明**：`api_config.json` 不要打进包（内含用户 API Key，且首次运行会自动生成）。

---

## 二、不要打进压缩包的内容

| 路径/规则 | 原因 |
|-----------|------|
| `api_config.json` | 可能含用户 Key；首次运行会自动创建 |
| `.git/` | 版本库，对方不需要 |
| `__pycache__/`、`*.pyc` | Python 缓存 |
| `dist/`、`build/` | 打包产物（若已用 `启动.bat` 选 4 打过 exe） |
| 虚拟环境目录（`venv/`、`.venv/` 等） | 对方应在本机自建或直接用系统 Python |

---

## 三、打包步骤（Windows）

1. 在项目根目录（如 `D:\ai软件集成`）确保存在 **请先读我.txt** 和 **首次安装指引.md**（见下一节）。
2. 选中除「二」中排除项以外的所有文件与文件夹。
3. 右键 → **发送到** → **压缩(zipped)文件夹**，或用 7-Zip/WinRAR 打成 zip。
4. 压缩包命名示例：`OVO-安装包-YYYYMMDD.zip`（压缩包/路径名避免使用尖括号等特殊符号）。

---

## 四、对方解压后的安装流程（零基础）

对方只需按 **首次安装指引.md**（或 **docs/安装总结.md**）操作即可，核心顺序：

1. **安装 Python 3.11 或 3.12**（必装），安装时**勾选「Add python.exe to PATH」**。
2. 解压压缩包到任意目录（路径不要含中文空格或特殊符号更佳）。
3. 双击 **检查安装.bat**，确认 **[1] Python**、**[2] 项目文件** 通过。
4. 双击 **启动.bat**，选 **1**（网页）或 **2**（桌面）打开 OVO。
5. 若要用 AI 回复：再按文档安装 Docker，在 **启动.bat** 中选 **3** 启动 LiteLLM，或在页面内配置 API。

详细步骤见 **首次安装指引.md**。

---

## 五、自检通过标准

- **[1] Python**：已安装且版本 ≥ 3.6（建议 3.11/3.12）。
- **[2] 项目文件**：`index.html`、`server_with_proxy.py`、`litellm/config.yaml` 均存在。
- **[3] 桌面版依赖**：仅用桌面内嵌窗口时需要；非必须。
- **[4][5][6][7]**：Docker、LiteLLM、Ollama、本地服务等，按需启动后再自检即可。

确保文档中写明：**只要 [1][2] 通过即可先启动界面**，[4]～[7] 为使用 AI 或本地模型时的可选/后续步骤。
