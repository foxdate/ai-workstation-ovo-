# 第 3 步：模型分组 / 标签

Open WebUI 官方镜像的模型列表没有「分组/标签」配置项，可用以下方式区分：

## 方式 A：双连接（推荐，零改代码）

在 **Settings → Connections** 里为 LiteLLM 建两个连接，同一 Base URL 和 API Key，通过「启用模型」区分：

| 连接名称     | Base URL                          | API Key  | 只启用模型 |
|-------------|------------------------------------|----------|------------|
| 国际模型     | `http://host.docker.internal:4000/v1` | `sk-1234` | grok-3-mini, grok-4, claude-sonnet, claude-haiku, gpt-4o, gpt-4o-mini |
| 中国模型     | `http://host.docker.internal:4000/v1` | `sk-1234` | qwen-turbo, qwen-plus, deepseek-chat, deepseek-reasoner, glm-4-flash, glm-4, kimi-moonshot-8k, kimi-moonshot-32k |

在模型选择里会按两个连接分组显示。中国模型可在 `litellm/config.yaml` 的 `model_info.description` 中写「中文理解 & 性价比极高」（若 UI 显示描述）。

## 方式 B：自定义前端

Fork Open WebUI，在模型选择界面加分组/标签逻辑并自建镜像，适合后续二次开发。
