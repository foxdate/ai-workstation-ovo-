# OVO - 多模态与图像生成

让接入的 AI 使用**原生能力**：看图（视觉）、看文件内容、生成图片。

## 一、让 AI「看图」与「看文件」

- **图片附件**：在输入框下方点击「+ 添加附件（图片/文本）」，选择图片。发送后，消息会以**多模态**格式（文字 + 图片）发给当前模型；支持视觉的 API（如 OpenAI Vision、通义千问多模态等）会根据图片内容回答。
- **文本附件**：选择 `.txt`、`.md`、`.json` 等文本文件时，内容会拼接到你的消息中，AI 可以基于文件内容回答。

使用方式：

1. 在输入框输入问题（可为空，仅发图时会自动加一句「请根据图片内容回答。」）。
2. 点击「+ 添加附件」选择一张或多张图片或文本文件。
3. 点击「发送」。  
  - 若有图片，请求会使用 OpenAI 兼容的 `content: [{ type: "text", text: "..." }, { type: "image_url", image_url: { url: "data:..." } }]` 格式，需当前 API 支持视觉。
  - 若仅有文本文件，会以纯文字形式发送。

**说明**：会议模式下多轮对话也会保留多模态消息格式；若某参会模型不支持视觉，该轮可能报错，可换用支持视觉的模型。

## 二、图像生成（画图）

- 在输入框输入**图片描述**，点击「**生成图片**」。
- 会调用当前所选模型对应 API 的 **`/images/generations`** 接口（OpenAI 风格），例如：
  - **OpenAI**：`dall-e-3`，需在 API 中配置 OpenAI Key。
  - 其他支持该路径的网关（如部分代理）也可用。

流程：

1. 选择已接入的、支持图像生成的 API 模型（不能是「插件」）。
2. 输入描述，点击「生成图片」。
3. 成功后，对话中会多两条记录：你的「[生成图片] 描述」和模型返回的图片。

**当前实现**：请求体使用 `model: "dall-e-3"`, `size: "1024x1024"`。若你的 API 使用不同模型名或尺寸，可后续在界面或配置中扩展。

**插件**：当前「生成图片」仅针对页面上配置的 API，不经过插件；插件如需画图，可在插件内部调用自己的接口。

## 三、小结

| 能力       | 入口               | 说明 |
|------------|--------------------|------|
| 看图       | 添加附件 → 选图片 → 发送 | 多模态消息，需 API 支持视觉 |
| 看文件     | 添加附件 → 选文本文件 → 发送 | 文件内容拼进消息文字 |
| 生成图片   | 输入描述 → 「生成图片」 | 调用当前 API 的 `/images/generations` |

这样，OVO中的 AI 即可使用**图像理解**与**图像生成**等原生能力；文件内容通过附件一并传给模型，便于做摘要、问答等。
