# OVO - 采集本机状态说明

通过 Python 脚本采集本机状态并写入工作区，使 Cursor 等 IDE 内的 AI 能读取「电脑当前状态」，从而结合系统信息回答问题或给出建议。

---

## 一、作用

- 在OVO中点击「**采集本机状态**」后，后端会运行 **`scripts/collect_computer_state.py`**，将结果写入 **`ovo_workspace/computer_state.json`**。
- 在 Cursor 中打开同一项目后，你可让 AI 读取该文件，例如：
  - 「读一下 `ovo_workspace/computer_state.json`，我电脑当前状态如何？」
  - 「根据 computer_state 和 state.json，结合我OVO里的对话，给我一些优化建议。」

AI 即可在**不直接访问你电脑**的前提下，基于这份快照了解系统、磁盘、进程、内存等情况。

---

## 二、采集内容（概览）

脚本仅使用 Python 标准库（及可选 `psutil`），采集内容**不包含**密码、密钥、浏览器历史等敏感数据。

| 项目       | 说明 |
|------------|------|
| 采集时间   | `collected_at` 时间戳 |
| 系统信息   | 操作系统、版本、架构、主机名 |
| 用户与路径 | 当前用户、当前工作目录、HOME/PATH 摘要 |
| 磁盘       | 各盘符/挂载点及总空间、可用空间（GB） |
| 内存       | 总/可用内存、占用率（需安装 `psutil`） |
| 进程列表   | PID、进程名、状态等（需安装 `psutil`，最多约 80 条） |

未安装 `psutil` 时仍会输出系统、用户、磁盘等；安装后补充进程与内存：`pip install psutil`。

---

## 三、使用步骤

1. 在OVO左侧「自我拓展」区域点击「**采集本机状态**」。
2. 等待几秒，提示「已写入 ovo_workspace/computer_state.json」即成功。
3. 在 Cursor 中对 AI 说：「读一下 `ovo_workspace/computer_state.json`」或「根据 computer_state 分析我电脑状态」。

可与「导出状态到工作区」配合使用：先导出OVO状态，再采集本机状态，然后让 AI 同时读 `state.json` 与 `computer_state.json`，结合对话与电脑状态一起分析。

---

## 四、脚本与接口

- **脚本路径**：项目内 `scripts/collect_computer_state.py`。
- **手动运行**（可选）：  
  `python scripts/collect_computer_state.py --output ovo_workspace/computer_state.json`  
  需在项目根目录执行；未指定 `--output` 时会将 JSON 打印到标准输出。
- **后端接口**：OVO前端通过 `POST /api/collect-computer-state` 触发采集，后端执行上述脚本并写入工作区。

---

## 五、隐私与安全

- 不读取浏览器数据、密钥、密码或敏感配置。
- 进程列表仅包含 PID、进程名、状态等常见信息。
- 所有结果仅写入本地项目下的 `ovo_workspace/`，不会自动上传；只有你在 Cursor 中主动让 AI 读该文件时，内容才会进入对话。

若需更少信息，可自行修改 `scripts/collect_computer_state.py`（例如注释掉进程列表或磁盘部分）后保存，再在OVO中重新点击「采集本机状态」。
