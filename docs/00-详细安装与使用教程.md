# OVO 详细安装与使用教程

本教程按「打开哪个页面、点哪里、做什么」一步步说明，从零到能正常对话。

**若暂无 API、想先把软件跑起来看界面**：只需 Python，按 [开发者必读](开发者必读.md) 第一节操作即可；再接 API 时再回到本教程。

---

## 一、需要提前安装的软件

### 1. Python（必装，用于运行网页/桌面版）

| 步骤 | 操作 |
|------|------|
| ① 打开页面 | 浏览器访问：**https://www.python.org/downloads/** |
| ② 下载 | 点击黄色按钮 **「Download Python 3.x.x」**，下载 Windows 安装包 |
| ③ 安装 | 双击安装包 → **务必勾选「Add Python to PATH」** → 点 **「Install Now」** → 完成 |
| ④ 验证 | 按 `Win + R`，输入 `cmd` 回车，在黑窗口输入 `python --version` 回车，能看到版本号即成功 |

### 2. Docker Desktop（必装，用于运行 LiteLLM 对接云模型）

| 步骤 | 操作 |
|------|------|
| ① 打开页面 | 浏览器访问：**https://www.docker.com/products/docker-desktop/** |
| ② 下载 | 点击 **「Download for Windows」**，下载 Docker Desktop 安装程序 |
| ③ 安装 | 双击安装 → 按提示完成，安装后**重启电脑**（若提示） |
| ④ 启动 | 从开始菜单打开 **「Docker Desktop」**，等待托盘图标就绪（不再转圈） |

### 3. Ollama（可选，用于本地免 Key 对话）

若不想申请任何 API Key，可只装 Ollama，用本机跑模型。

| 步骤 | 操作 |
|------|------|
| ① 打开页面 | 浏览器访问：**https://ollama.com** |
| ② 下载 | 点击 **「Download」**，选择 Windows 版本下载 |
| ③ 安装 | 双击安装包，按提示完成；安装后 Ollama 会在后台运行 |
| ④ 拉取模型 | 按 `Win + R`，输入 `cmd` 回车，在黑窗口输入下面任一命令回车（首次会下载）：<br>• `ollama run qwen2:7b`（推荐，中文好）<br>• 或 `ollama run llama3.2:3b`<br>下载完成后可关掉该窗口，Ollama 会继续在后台运行 |

## 二、项目文件放在哪里

- 假设你把整个项目放在：**`D:\ai软件集成`**（也可以是其他盘、其他文件夹）。
- 确保该文件夹里有这些文件/文件夹：
  - **启动.bat**（菜单：1 网页 / 2 桌面 / 3 LiteLLM / 4 打包）
  - **index.html**
  - **server_with_proxy.py**
  - **litellm** 文件夹（里面有 **config.yaml**）
  - **检查安装.bat**（安装后自检；末尾可选安装 pywebview）

---

## 二点五、安装后自检（确保软件能接入）

装完 Python / Docker / Ollama 并把项目放到目录后，先做一次自检，确认环境能让OVO正常接入。

| 步骤 | 操作 |
|------|------|
| ① 打开项目文件夹 | 打开 **文件资源管理器**，进入 **`D:\ai软件集成`**（你的项目目录） |
| ② 运行自检 | 双击 **「检查安装.bat」** |
| ③ 看黑窗口里的报告 | 会依次检查：<br>• **[1] Python**：版本是否 3.6+，通过即可<br>• **[2] 项目文件**：index.html、server_with_proxy.py、litellm/config.yaml 是否都在，有「缺失」就补文件<br>• **[3] 桌面版依赖**：用桌面版才需要 pywebview，没有就执行 `pip install pywebview` 或在「检查安装.bat」末尾选 Y<br>• **[4] Docker**：要用云模型/通义等需「已安装且正在运行」，否则先装并打开 Docker Desktop<br>• **[5] LiteLLM 端口 4000**：未启动时显示「未检测到」，正常；等会儿「启动.bat」选 3 后会变成「已就绪」<br>• **[6] Ollama**：用免 Key 本地模型才需要「已就绪」，否则可忽略<br>• **[7] 本地网页服务**：未启动时显示「未启动」，正常；等会儿「启动.bat」选 1 或 2 后会显示端口已在使用 |
| ④ 根据提示补全 | 若 **[1][2]** 有未通过项，先补全（装 Python、补全项目文件）；若要用云模型且 **[4]** 未通过，先安装并打开 Docker；若要用桌面版且 **[3]** 未安装 pywebview，执行 `pip install pywebview` |
| ⑤ 再跑一次自检（可选） | 补全后可以再双击 **「检查安装.bat」** 看一遍，确认 **[1][2]** 都通过。**[5][6][7]** 在还没启动 LiteLLM / 本地服务时显示「未检测到」或「未启动」是正常的，按下面「三」或「四」启动后再用即可 |

自检通过（至少 [1][2] 通过）后，即可按下面「三、用网页方式使用」或「四、用桌面软件方式使用」启动并接入软件。

## 三、用「网页」方式使用（浏览器里打开）

### 第 1 步：启动 LiteLLM（AI 后端）

| 步骤 | 操作 |
|------|------|
| ① 打开文件夹 | 打开 **文件资源管理器**，进入 **`D:\ai软件集成`**（你的项目目录） |
| ② 双击运行 | 双击 **「启动.bat」**，选 **3**（LiteLLM） |
| ③ 看输出 | 应出现 **「LiteLLM 已启动。」** 或 Docker 成功提示；若「未找到 Docker」，请先安装并打开 Docker Desktop |
| ④ 保持运行 | LiteLLM 在 **Docker 后台**运行；停止请用 **`docker stop litellm`**，不要误以为需要常驻某个黑窗口 |

### 第 2 步：启动本地网页服务

| 步骤 | 操作 |
|------|------|
| ① 再开一个 | 再次打开 **`D:\ai软件集成`** 文件夹 |
| ② 双击运行 | 双击 **「启动.bat」**，选 **1**（本地网页服务） |
| ③ 等待 | 会新开一个服务器窗口，约 3 秒后**自动打开浏览器**；若未打开，请手动访问 **http://localhost:8888/** 或 **http://localhost:9000/** |

### 第 3 步：在浏览器里使用

| 步骤 | 操作 |
|------|------|
| ① 进入界面 | 浏览器会打开OVO页面：左侧是「最新 AI 技术亮点」，右侧是对话区 |
| ② 选模型 | 在页面顶部 **「当前模型」** 下拉框里选一个模型：<br>• 若已装 Ollama 并拉过模型：选 **「Ollama Qwen2 7B (免 Key)」** 等带「免 Key」的<br>• 若要用通义/DeepSeek 等：需先在下面「四、配置 API Key」里填好 Key 再选对应模型 |
| ③ 发消息 | 在底部输入框输入文字，点 **「发送」**，即可收到 AI 回复 |

## 四、用「桌面软件」方式使用（不打开浏览器）

### 第 1 步：依赖（可选）

| 步骤 | 操作 |
|------|------|
| 不装依赖 | 直接 **「启动.bat」** 选 **2**，会用**默认浏览器**打开，功能正常使用。 |
| 要内嵌窗口 | 需安装 pywebview，详见 **[docs/如何安装依赖.md](如何安装依赖.md)**；或先运行 **「检查安装.bat」** 末尾选 Y 尝试自动安装。 |

### 第 2 步：启动 LiteLLM（与网页版相同）

| 步骤 | 操作 |
|------|------|
| ① 打开文件夹 | 进入 **`D:\ai软件集成`** |
| ② 双击运行 | **「启动.bat」** 选 **3**，看到 **「LiteLLM 已启动。」** 即可（容器在 Docker 后台运行） |

### 第 3 步：打开桌面版窗口

| 步骤 | 操作 |
|------|------|
| ① 双击运行 | 在 **`D:\ai软件集成`** 里 **「启动.bat」** 选 **2** |
| ② 弹出窗口 | 会弹出一个标题为 **「OVO」** 的窗口，界面与网页版一致 |
| ③ 选模型、发消息 | 在窗口内选择「当前模型」、输入文字发送，用法与网页版相同 |
| ④ 关闭 | 关掉该窗口即退出；需要时再 **「启动.bat」** 选 **2** 即可 |

## 五、配置 API Key（要用通义 / DeepSeek / GPT 等云模型时）

只有当你选择**非「免 Key」模型**（如通义千问、DeepSeek、GPT 等）时，才需要配置；只用 Ollama 可跳过本节。

### 5.1 获取通义千问（阿里云）API Key

| 步骤 | 操作 |
|------|------|
| ① 打开页面 | 浏览器访问：**https://dashscope.console.aliyun.com/** |
| ② 登录 | 用**阿里云账号**登录（没有则先注册） |
| ③ 开通服务 | 若首次使用，按页面提示开通「模型服务灵积（Dashscope）」 |
| ④ 创建 Key | 在左侧或页面中找到 **「API-KEY 管理」**，点击 **「创建新的 API-KEY」**，复制生成的 Key（形如 `sk-xxxxxxxx`） |

### 5.2 把 Key 填进项目配置

| 步骤 | 操作 |
|------|------|
| ① 打开配置文件 | 用**记事本**或 **VS Code** 打开：**`D:\ai软件集成\litellm\config.yaml`** |
| ② 搜索占位符 | 按 `Ctrl + F`，搜索：**your-dashscope-api-key** |
| ③ 替换 | 把 **两处** `your-dashscope-api-key` 都改成你复制的通义 Key，例如：<br>`api_key: "sk-你复制的Key"` |
| ④ 保存 | 按 `Ctrl + S` 保存并关闭 |
| ⑤ 重启 LiteLLM | 命令行执行 **`docker restart litellm`**，或 **`docker stop litellm`** 后重新 **「启动.bat」** 选 **3** |

之后在页面里选 **「通义千问 Turbo」** 或 **「通义千问 Plus」** 即可正常对话。

### 5.3 其他模型 Key 的获取与配置

| 模型 | 获取 Key 的页面 | 在 config.yaml 里要替换的占位符 |
|------|----------------|----------------------------------|
| DeepSeek | https://platform.deepseek.com/ | your-deepseek-api-key |
| 智谱 GLM | https://open.bigmodel.cn/ | your-zhipu-api-key |
| Kimi 月之暗面 | https://platform.moonshot.cn/ | your-moonshot-api-key |
| OpenAI GPT | https://platform.openai.com/ | your-openai-api-key |

打开对应页面 → 注册/登录 → 在「API Key」或「密钥」类页面创建并复制 Key → 在 **`litellm\config.yaml`** 里搜索上表「占位符」，替换为你的 Key → 保存后**重启 LiteLLM**（`docker restart litellm` 或「启动.bat」选 3 重新创建容器）。

## 六、常见问题速查

| 现象 | 处理办法 |
|------|----------|
| 浏览器打开 localhost:8888 显示「无法访问」或「未发送数据」 | 确认已 **「启动.bat」** 选 **1**，且本地服务窗口未关；若写的是 9000，则访问 **http://localhost:9000/** |
| 发送消息后提示「无法连接 LiteLLM」 | 先 **「启动.bat」** 选 **3**，等出现「LiteLLM 已启动。」再发消息；并确认 Docker Desktop 已打开 |
| 选「通义千问」等模型报错「Incorrect API key」 | 按上面「五、配置 API Key」在 **litellm\config.yaml** 里填好对应 Key，保存后 **`docker restart litellm`** |
| 想完全不填 Key 就用 | 安装 **Ollama**，在 cmd 里执行一次 `ollama run qwen2:7b`，然后在页面里选 **「Ollama Qwen2 7B (免 Key)」** |
| 双击 bat 闪退或报错 | 确认已安装 **Python** 且安装时勾选了「Add Python to PATH」；若仍报错，在 cmd 里先 `cd` 到项目目录，再运行 `python server_with_proxy.py` 或 `python desktop_app.py` 看具体报错信息 |
| 桌面版提示「请先安装依赖」或 pip 报错 **Failed building wheel for pythonnet** | 可试 **`pip install pywebview[cef]`**；或**不装**，直接再 **「启动.bat」** 选 **2**，程序会用默认浏览器打开，功能相同。 |

## 七、流程小结（按顺序做即可）

1. **装好**：Python、Docker Desktop；可选 Ollama（免 Key）。
2. **放好项目**：把整个项目放到一个目录（如 `D:\ai软件集成`），确保文件齐全。
3. **自检**：双击 **「检查安装.bat」**，确认 [1] Python、[2] 项目文件 通过；其余项按需补全。桌面版依赖可在自检末尾安装，或首次「启动.bat」选 2 时用浏览器方式。
4. **启动后端**：**「启动.bat」** 选 **3**，看到「LiteLLM 已启动。」。
5. **打开界面**：  
   - **网页**：**「启动.bat」** 选 **1**，浏览器访问 **http://localhost:8888/**（或提示的端口）；  
   - **桌面**：**「启动.bat」** 选 **2**。
6. **选模型**：选「免 Key」的 Ollama 模型，或已配置 Key 的云模型。
7. **发消息**：在输入框输入内容点「发送」即可。

更细的 API Key 说明见 [05-API-Key-配置说明.md](05-API-Key-配置说明.md)，桌面版打包成 exe 见 [07-桌面版使用与打包.md](07-桌面版使用与打包.md)。
