# 插件接入与数据互通

OVO支持通过**插件**接入外部 AI 或工具，实现与OVO的**数据互通**。同一套方式也可用于拓展其他 AI 工具。

---

## 一、在OVO里添加插件

1. 左侧栏找到 **「🧩 插件」** 区域。
2. 点击 **「+ 添加插件」**，填写：
   - **名称**：如「Cursor」「自建助手」。
   - **插件地址**：你的插件服务根地址（见下方协议），例如 `http://127.0.0.1:3001` 或 `https://your-server.com/agent`。
   - **API Key**：可选，若插件需要鉴权则填写。
3. 点击 **「保存插件」**。
4. 在 **「当前模型」** 下拉中会多出一个 **「插件」** 分组，选择刚保存的插件即可与之对话。

OVO会把**当前对话历史 + 用户新消息**发给插件，并展示插件返回的文本，实现数据互通。

---

## 二、插件端需实现的协议

OVO通过本机服务（`server_with_proxy.py`）**转发**请求到你的插件，避免浏览器跨域。插件只需提供 **一个 HTTP 接口**，按下列约定收发数据即可。

### 请求

- **方法**：`POST`
- **路径**：插件根地址末尾加上 `/chat`。  
  例如插件地址填 `http://127.0.0.1:3001`，则OVO请求 `http://127.0.0.1:3001/chat`；若填 `https://x.com/agent`，则请求 `https://x.com/agent/chat`。
- **Headers**：  
  - `Content-Type: application/json`  
  - 若在OVO里填了 API Key，会带 `Authorization: Bearer <你的 Key>`
- **Body（JSON）**：
  ```json
  {
    "messages": [
      { "role": "user", "content": "用户之前说的话" },
      { "role": "assistant", "content": "AI 之前的回复" }
    ],
    "newMessage": "用户刚发的一条新消息"
  }
  ```
  - `messages`：到当前为止的**完整对话历史**（含角色与内容）。
  - `newMessage`：用户**本条**刚输入的消息。插件可据此实现「只处理新消息」或「结合全文理解」。

### 响应

- **Content-Type**：建议 `application/json; charset=utf-8`。
- **Body（JSON）** 需包含以下其一，OVO会当作「本条回复」展示：
  - `content`：字符串，推荐。
  - 若无 `content`，会退化为使用 `reply` 或 `text`。
  - 出错时可在 JSON 里返回 `error`，OVO会展示为 `[插件错误: ...]`。

示例：

```json
{
  "content": "这是插件返回的回复内容。"
}
```

错误示例：

```json
{
  "error": "服务暂时不可用",
  "content": ""
}
```

---

## 三、数据互通含义

- **OVO → 插件**：每次用户发送消息时，OVO会把 **当前会话的 messages + newMessage** 发给你的插件，插件可拿到完整上下文。
- **插件 → OVO**：插件返回的 **content** 会作为一条「助手」消息追加到当前对话，并参与后续轮次，实现与OVO的对话数据互通。
- **拓展其他 AI 工具**：只要该工具能提供上述 `POST /chat` 接口（或你写一层网关转成此格式），在OVO里添加为插件即可，用法与接入「我」相同。

---

## 四、简单示例（本地插件服务）

例如用 Python 快速起一个本地插件，供OVO调用：

```python
# plugin_example.py
from http.server import HTTPServer, BaseHTTPRequestHandler
import json

class Handler(BaseHTTPRequestHandler):
    def do_POST(self):
        if self.path != "/chat":
            self.send_response(404)
            self.end_headers()
            return
        length = int(self.headers.get("Content-Length", 0))
        raw = self.rfile.read(length).decode("utf-8")
        data = json.loads(raw)
        messages = data.get("messages", [])
        new_message = data.get("newMessage", "")
        # 此处可调用你的 AI、Cursor 接口或任何逻辑，生成 reply
        reply = "收到：" + new_message + "（历史消息数：" + str(len(messages)) + "）"
        self.send_response(200)
        self.send_header("Content-Type", "application/json; charset=utf-8")
        self.end_headers()
        self.wfile.write(json.dumps({"content": reply}, ensure_ascii=False).encode("utf-8"))

HTTPServer(("127.0.0.1", 3001), Handler).serve_forever()
```

运行后，在OVO插件里填地址 `http://127.0.0.1:3001`，保存并选择该插件即可对话，实现数据互通。接入「我」或其它 AI 时，只需把上面 `reply` 的生成改为调用对应 API 或服务即可。
