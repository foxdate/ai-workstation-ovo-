# 如何安装依赖

OVO **仅提供桌面窗口**（pywebview 内嵌），不再支持「只开系统浏览器、不装 pywebview」。

---

## 无法安装 pywebview（pythonnet）的原因

你看到的 **Building wheel for pythonnet ... error** 主要来自：

1. **Python 版本过新**（如 3.14）：pythonnet 可能没有预编译 wheel，需从源码编译。
2. **pywebview 在 Windows 上常依赖 pythonnet**：编译失败则整次安装失败。
3. **NuGet / 网络问题**：pythonnet 构建时调用 NuGet 失败。

**可行做法**：换用 **Python 3.11/3.12**，或只装 **CEF**（`pywebview[cef]`），或使用 **`build_exe.bat`** 生成 **OVO.exe**（在已能装 pywebview 的环境上打包）。

---

## 一、推荐：检查安装脚本

运行 **「检查安装.bat」**，末尾选 **Y**，会依次尝试 `pip install pywebview` 与 `pip install "pywebview[cef]"`。

---

## 二、手动安装 pywebview

1. 打开 **cmd** 或 **PowerShell**。
2. 执行：
   ```bash
   pip install pywebview
   ```
   若报错 `Failed building wheel for pythonnet`：
   ```bash
   pip install "pywebview[cef]"
   ```
3. 再 **「启动.bat」** 选 **1** 启动桌面。

---

## 三、换用 Python 3.11/3.12 再装

1. 从 https://www.python.org/downloads/ 安装 **3.11 或 3.12**，勾选 **Add python.exe to PATH**。
2. 执行：
   ```bash
   py -3.12 -m pip install pywebview
   ```
3. **「启动.bat」** 会通过 `:find_py` 优先使用 3.12/3.11；也可编辑 `启动.bat` 调整 `:find_py` 顺序。

---

## 四、仍失败时

- 使用 **`build_exe.bat`** 在能成功安装 pywebview 的机器上生成 **dist\OVO.exe**，在未装 Python 的电脑上运行 exe。
- 若 CEF 方案仍失败，见 [07-桌面版使用与打包.md](07-桌面版使用与打包.md) 中的说明。

---

## 五、小结

| 方式 | 依赖 | 说明 |
|------|------|------|
| **启动.bat** 选 **1** | pywebview | 源码运行桌面 |
| **build_exe.bat** | 打包机需 PyInstaller + pywebview | 生成 **OVO.exe** |
| **启动.bat** 选 **2** | Docker | 仅启动 LiteLLM，与 OVO 桌面无关 |
