# 如何安装依赖

OVO不同使用方式需要的依赖不同，按下面说明操作即可。

---

## 无法安装桌面依赖（pywebview）的原因

你看到的 **Building wheel for pythonnet ... error** 主要来自这三层原因：

1. **Python 版本过新**  
   当前若为 **Python 3.14**，pythonnet 没有为其提供预编译 wheel，pip 只能**从源码编译**。编译需要 .NET/NuGet 环境，步骤多、容易失败。

2. **pywebview 在 Windows 上依赖 pythonnet**  
   无论是 `pip install pywebview` 还是 `pip install "pywebview[cef]"`，在 Windows 上都会拉取 pythonnet。只要 pythonnet 编译失败，整次安装就会报错。

3. **pythonnet 编译时 NuGet 报错**  
   报错里的 `Command 'tools\nuget\nuget.exe update -self' returned non-zero exit status 1` 表示 pythonnet 在构建时调用 NuGet 失败（网络、权限或环境不全），导致 wheel 建不出来。

**结论**：不是你的操作问题，而是「Python 3.14 + Windows + pywebview 依赖 pythonnet 且需从源码编译」这一组合在当前环境下难以成功。  
**可行做法**：换用 Python 3.11/3.12 再装（见下「四」），或只装 CEF 绕过 pythonnet，或**不装 pywebview**、直接用「启动.bat」选 2 用浏览器打开（功能一致）。

---

## 一、只用「网页版」（推荐，零依赖）

- **启动方式**：**「启动.bat」** 选 **1**，浏览器打开 **http://localhost:8888/**（或提示的端口）。
- **依赖**：只需本机已安装 **Python**，无需执行任何 `pip install`。
- 若未装 Python，请先安装：https://www.python.org/downloads/ ，安装时勾选 **Add Python to PATH**。

---

## 二、用「桌面版」时的依赖

桌面版有两种用法，二选一即可。

### 方式 A：不装任何 pip 依赖（用浏览器当窗口）

- **操作**：直接 **「启动.bat」** 选 **2**，不执行任何 pip。
- **效果**：程序会启动本地服务并**自动用默认浏览器**打开页面，功能与内嵌窗口一致。
- **依赖**：仅需 Python，无需安装 pywebview。

### 方式 B：安装 pywebview（内嵌独立窗口）

若希望弹出**独立应用窗口**而不是浏览器标签，需要安装 **pywebview**。

**步骤：**

1. 打开 **命令提示符（cmd）** 或 **PowerShell**。
2. 执行（任选一种，推荐先试第 ① 种）：
   - **① 标准安装：**
     ```bash
     pip install pywebview
     ```
   - **② 若第 ① 报错（例如 `Failed building wheel for pythonnet`），改用 CEF 版：**
     ```bash
     pip install "pywebview[cef]"
     ```
     CEF 包较大，下载时请耐心等待。
3. 安装成功后，再 **「启动.bat」** 选 **2**，即会弹出 OVO 内嵌窗口。

**若两种都安装失败**（例如本机 pythonnet 编译失败）：  
可直接用方式 A，不装 pywebview，照常「启动.bat」选 2，用浏览器打开即可，功能相同。

---

## 三、一键尝试安装（可选）

- 运行 **「检查安装.bat」**，末尾选 Y，会依次尝试 `pip install pywebview` 和 `pip install "pywebview[cef]"`。
- 若都失败，不影响使用：直接「启动.bat」选 1 或 2 即可用浏览器方式使用。

---

## 四、手动安装桌面依赖（排查 pythonnet 失败）

当 `pip install pywebview` 和 `pip install "pywebview[cef]"` 都报 **Building wheel for pythonnet ... error** 时，可按下述顺序**手动**尝试，便于排查。

### 方案 1：换 Python 版本（推荐先试）

本机若为 **Python 3.14** 或过新版本，pythonnet 常无预编译 wheel，只能从源码编译，易失败。

**步骤一：安装 Python 3.11 或 3.12**

1. 打开 https://www.python.org/downloads/
2. 往下找到 **Python 3.11.x** 或 **Python 3.12.x**，点进去下载 **Windows installer (64-bit)**。
3. 运行安装程序，**务必勾选「Add python.exe to PATH」**，再点「Install Now」。  
   若本机已有 3.14，可勾选「Install for all users」或自定义安装路径（如 `C:\Python311`），避免覆盖 3.14。

**步骤二：用 3.11/3.12 安装依赖**

- 打开 **cmd** 或 **PowerShell**，任选一种方式：

  **方式 A（推荐）** — 用 Windows 的 `py` 启动器指定版本：
  ```bash
  py -3.11 -m pip install pywebview
  ```
  若装的是 3.12，把 `-3.11` 改成 `-3.12`。若提示没有 `py`，用方式 B。

  **方式 B** — 用 3.11/3.12 的完整路径（安装路径以你本机为准）：
  ```bash
  "C:\Users\你的用户名\AppData\Local\Programs\Python\Python311\python.exe" -m pip install pywebview
  ```
  或若装在 `C:\Python311`：
  ```bash
  C:\Python311\python.exe -m pip install pywebview
  ```

**步骤三：用同一版本运行桌面版**

- 用 3.11 装的依赖，就要用 3.11 跑桌面版，例如：
  ```bash
  py -3.11 desktop_app.py
  ```
  或：
  ```bash
  C:\Python311\python.exe desktop_app.py
  ```
- 若希望**固定用 3.11**：右键「启动.bat」→ 编辑，在 `:find_py` 段调整 `py -3.11` / `python` 的优先级，保存后再运行。

### 方案 2：只装 CEF，绕过 pythonnet

pywebview 在 Windows 上可选用 CEF 后端（不依赖 pythonnet），可单独装 CEF 再装 pywebview（不装其默认依赖）：

1. 打开 **cmd** 或 **PowerShell**，依次执行：
   ```bash
   pip install cefpython3
   pip install pywebview --no-deps
   pip install bottle proxy_tools typing_extensions
   ```
2. 若全部成功，再 **「启动.bat」** 选 **2**。桌面版会优先尝试 CEF 后端（`gui="cef"`），有机会出现内嵌窗口。
3. 若仍报错或无法启动，改用下方「不装 pywebview」方式。

### 方案 3：不装 pywebview（无内嵌窗口）

- **不执行任何** `pip install pywebview`。
- 直接 **「启动.bat」** 选 **2**，程序会**用默认浏览器**打开页面，功能与内嵌窗口一致，仅窗口在浏览器中。

---

## 五、小结

| 使用方式           | 需要装的依赖     | 说明                         |
|--------------------|------------------|------------------------------|
| 启动.bat 选 1      | 无               | 仅需 Python，浏览器打开页面  |
| 启动.bat 选 2      | 无 或 pywebview  | 不装则用浏览器；装则内嵌窗口 |

**建议**：若不想折腾依赖，用 **「启动.bat」** 选 1 或 2（不装 pywebview）即可正常使用。  
**pythonnet 编译失败时**：按上面「四、手动安装桌面依赖」逐条尝试，或直接用方案 3（不装 pywebview）。
