# OVO 安装总结

从零到可用的完整安装顺序：**环境 → 依赖 → 软件（项目）→ 启动**。按需执行，不必全部做完才能用。

---

## 一、环境安装

### 1.1 Python（必装）

| 项目 | 说明 |
|------|------|
| **作用** | 运行OVO网页/桌面、本地服务与代理。 |
| **下载** | https://www.python.org/downloads/ |
| **版本建议** | **3.11 或 3.12**（桌面内嵌窗口依赖 pywebview，在 3.11/3.12 下更易安装；3.14 易遇 pythonnet 编译失败）。 |
| **安装注意** | 安装时**勾选「Add python.exe to PATH」**。 |
| **验证** | 打开 cmd，输入 `python --version` 或 `py -3.12 --version`，能显示版本即成功。 |

### 1.2 Docker Desktop（可选，用于云模型）

| 项目 | 说明 |
|------|------|
| **作用** | 运行 LiteLLM，对接通义、DeepSeek、GPT 等云 API。 |
| **下载** | https://www.docker.com/products/docker-desktop/ |
| **何时需要** | 要用网页/桌面里的「通义千问」「DeepSeek」「GPT」等云模型时再装。 |
| **验证** | 安装并启动 Docker Desktop 后，在 cmd 输入 `docker info` 不报错即成功。 |

### 1.3 Ollama（可选，用于本地免 Key 模型）

| 项目 | 说明 |
|------|------|
| **作用** | 本机跑开源模型，无需 API Key。 |
| **下载** | https://ollama.com |
| **何时需要** | 想用「Ollama Qwen2 7B (免 Key)」等本地模型时再装；装后执行一次 `ollama run qwen2:7b` 拉取模型。 |

---

## 二、依赖安装

### 2.1 桌面版（必装 pywebview）

| 依赖 | 操作 |
|------|------|
| **pywebview** | 运行 **「检查安装.bat」** 末尾按提示安装；或手动：`py -3.12 -m pip install pywebview`。 |
| **单文件 exe** | 运行 **build_exe.bat** 生成 `dist\OVO.exe`，无需单独装 Python。 |

若安装 pywebview 时报 **pythonnet 编译失败**，见 [如何安装依赖](如何安装依赖.md) 中的「无法安装桌面依赖的原因」和「手动安装」方案（换 3.11/3.12 或只装 CEF）。

---

## 三、软件安装（项目）

OVO无需「安装程序」，把**项目文件夹**放到本机即可。

| 项目 | 说明 |
|------|------|
| **获取项目** | 将整个项目目录拷贝到本地，例如 `D:\ai软件集成`。 |
| **必要内容** | 目录内需有：`index.html`、`server_with_proxy.py`、`litellm\config.yaml`，以及 `启动.bat`、`build_exe.bat`、`检查安装.bat`。 |
| **自检** | 双击 **「检查安装.bat」**，确认 [1] Python、[2] 项目文件 通过。 |

---

## 四、启动与使用

| 用途 | 操作 |
|------|------|
| **打开 OVO 桌面** | **「启动.bat」** 选 **1**，或双击 **dist\OVO.exe**。 |
| **要 AI 回复（云模型）** | 先启动 **Docker**，再 **「启动.bat」** 选 **2**（LiteLLM），然后在页面选模型、填好 API Key（见 [05-API-Key-配置说明](05-API-Key-配置说明.md)）。 |
| **要 AI 回复（本地免 Key）** | 安装并运行 **Ollama**，执行 `ollama run qwen2:7b`，**先开 Ollama 再**「启动.bat」选 **2**，在页面选 Ollama 模型。 |

---

## 五、安装顺序速览

```
1. 安装 Python 3.11 或 3.12（必装）
2. 可选：安装 Docker（云模型）、Ollama（本地免 Key）
3. 依赖：在「检查安装.bat」末尾选 Y 安装 pywebview，或使用 **build_exe.bat** 生成 exe
4. 将项目放到目录，可选运行「检查安装.bat」自检
5. 启动：**「启动.bat」** 选 1 打开桌面；要 AI 则再选 2（LiteLLM）
```
