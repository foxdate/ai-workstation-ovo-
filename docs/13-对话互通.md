# OVO - 对话互通（AI 工作站重点）

OVO的定位是 **AI 工作站**：接入多个 AI 软件/模型，**重点是把各处的对话内容互通**——把 A 软件的对话给 B 软件用，或在OVO里换一个 AI 继续同一段对话。

---

## 一、为什么做对话互通

- **多 AI 协同**：在软件 A 里聊完一段，把对话导出，导入到软件 B（或OVO里另一个模型），换 AI 继续回答、总结、翻译等。
- **统一入口**：OVO内可同时用多个 API/插件模型；通过「导出对话 → 导入对话」，把其他 AI 软件（如 Cursor、其他聊天工具）里的对话迁入OVO，用OVO里的模型接着聊。
- **格式统一**：使用同一套 JSON 格式，任何支持该格式的软件都可以和OVO互相导入/导出，实现 A↔B 互通。

---

## 二、在OVO里怎么用

### 导出对话（把当前对话给 B 软件）

1. 在OVO中切到要导出的那条对话（对应一个 tab）。
2. 点击 tab 栏右侧的「**导出对话**」。
3. 系统会：
   - 将当前对话生成为标准 JSON（见下方格式），**复制到剪贴板**；
   - 同时写入项目工作区 **`ovo_workspace/conversation_export.json`**（若你从项目目录启动OVO）。
4. 在「B 软件」中：若支持导入，可粘贴该 JSON 或打开 `conversation_export.json` 导入；在OVO的另一个 tab 或另一台机器上的OVO，可用「导入对话」接上这段对话。

### 导入对话（把 A 软件的对话接到OVO）

1. 点击 tab 栏右侧的「**导入对话**」。
2. 任选其一：
   - **选择文件**：选一个 `.json` 文件（例如从 A 软件导出的对话、或之前的 `conversation_export.json`）；
   - **粘贴 JSON**：把对话 JSON 粘贴到输入框。
3. 点击「**确定导入**」。
4. OVO会**新建一个 tab**，其中包含导入的 `messages`；若 JSON 里带 `model` 且OVO中有该模型，会优先选中该模型，否则用当前默认模型。你可以在OVO里**换一个 AI** 继续这段对话。

---

## 三、对话 JSON 格式（互通标准）

导出/导入使用同一套结构，便于各软件统一解析：

```json
{
  "version": "1",
  "source": "OVO",
  "messages": [
    { "role": "user", "content": "用户说的话" },
    { "role": "assistant", "content": "AI 回复", "speaker": "可选，发言人名称" }
  ],
  "model": "可选，模型 ID",
  "meetingOrder": null,
  "exported_at": "2025-03-07T12:00:00.000Z"
}
```

- **必填**：`messages`，数组，每项为 `{ "role": "user"|"assistant", "content": "..." }`；可带 `speaker`。
- **可选**：`model`（OVO内模型 ID）、`meetingOrder`（会议顺序）、`source`、`exported_at` 等。
- 多模态：`content` 可以是字符串，也可以是数组（如 `[{ "type": "text", "text": "..." }, { "type": "image_url", "image_url": { "url": "..." } }]`），与OVO内部表示一致即可。

其他 AI 软件只要导出上述结构的 JSON（至少含 `messages`），即可被OVO「导入对话」识别；OVO导出的 JSON 也可被支持该格式的 B 软件导入。

---

## 四、典型场景

| 场景 | 操作 |
|------|------|
| 在OVO用模型 A 聊完，换模型 B 继续 | 当前 tab 点「导出对话」，再点「导入对话」粘贴刚复制的 JSON，在新 tab 里选模型 B 继续发消息。 |
| 从 Cursor / 其他工具迁到OVO | 在对方软件中导出为上述 JSON（或兼容的 messages 数组），在OVO「导入对话」选文件或粘贴。 |
| 把OVO的对话拿到别的软件用 | OVO「导出对话」后，粘贴或发送 `conversation_export.json` 给 B 软件；若 B 支持同格式即可导入。 |

---

## 五、小结

- **导出对话**：当前 tab 的对话 → 标准 JSON → 剪贴板 + 工作区 `conversation_export.json`，便于给 B 软件或本机其他 tab 用。
- **导入对话**：从文件或粘贴的 JSON 读入 `messages`（及可选 `model`）→ 在OVO新建 tab，换 AI 继续聊。
- 本软件重点在 **AI 工作站** 与 **对话互通**：把 A 软件的对话给 B 软件，或在OVO内多模型之间延续同一段对话。
