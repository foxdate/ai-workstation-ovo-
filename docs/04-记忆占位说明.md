# 第 4 步：永不遗忘（记忆占位方案）

当前使用本地文件占位，后续可接入 Mem0 或自建向量库。

## 使用方式

1. **查看历史总结**：打开 `memory_store/chat_summaries.txt`。
2. **追加一条总结**（二选一）：
   - 命令行：`python scripts/append_summary.py 会话ID 一句话总结`
   - 或：`echo 一句话总结 | python scripts/append_summary.py 会话ID`
3. **下次同主题聊天**：把上一条总结复制到首条消息，例如：「上次我们做到这里：…… 请在此基础上继续。」

## 示例

```bash
cd D:\ai软件集成
python scripts/append_summary.py default 用户确认了 LiteLLM 连接成功，下一步要配置模型分组
```
