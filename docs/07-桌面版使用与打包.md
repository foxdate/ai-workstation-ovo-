# OVO 桌面版（脱离网页运行）

桌面版以独立窗口运行，不再需要单独打开浏览器。

## 方式一：直接运行（开发 / 日常使用）

1. 安装依赖（仅首次）：
   ```bash
   pip install pywebview
   ```
   若报错 **Failed building wheel for pythonnet**，可改用（二选一）：
   ```bash
   pip install pywebview[cef]
   ```
   或**不装 pywebview**，直接 **`启动.bat`** 选 **2**：程序会自动用**默认浏览器**打开页面，功能相同，只是窗口在浏览器里。
2. **`启动.bat`** 选 **2**，或在项目目录执行：
   ```bash
   python desktop_app.py
   ```
3. 若已装 pywebview：会弹出「OVO」内嵌窗口；若未装或安装失败：会自动用浏览器打开，关掉浏览器后回到黑窗口按回车结束服务。

使用前请先按需启动 **LiteLLM**（`启动.bat` 选 3）或 **Ollama**，否则对话会提示无法连接后端。

### 安装 pywebview 报错（pythonnet）时怎么办

| 情况 | 做法 |
|------|------|
| 报错里有 `Failed building wheel for pythonnet` | 先试 **`pip install pywebview[cef]`**（用 CEF 内核，不依赖 pythonnet）；若仍失败，可不装，直接「启动.bat」选 2，用自动打开的浏览器即可。 |
| 不想装任何额外依赖 | 用 **「启动.bat」** 选 **1**，再在浏览器地址栏输入 **http://localhost:8888/**，效果与桌面版一致。 |

## 方式二：打包成 exe（单文件软件）

1. 安装打包依赖：
   ```bash
   pip install pyinstaller pywebview
   ```
2. **`启动.bat`** 选 **4**，或在项目根目录执行：
   ```bash
   pyinstaller --noconfirm --onefile --windowed --name "OVO" --add-data "index.html;." --add-data "highlights.html;." --hidden-import "webview" desktop_app.py
   ```
   （`--name` 须为合法文件名；界面标题仍为 `OVO`。）
3. 打包完成后，在 **`dist`** 目录下会生成 **`OVO.exe`**。
4. 将 **OVO.exe** 复制到任意位置，双击即可运行，无需安装 Python。

说明：
- 静态页面（index.html、highlights.html）已打进 exe，无需同目录放网页文件。
- AI 对话仍需本机先运行 LiteLLM（Docker）或 Ollama；exe 只提供界面与本地代理。

## 与网页版的区别

| 项目     | 网页版                     | 桌面版                         |
|----------|----------------------------|--------------------------------|
| 打开方式 | 浏览器访问 localhost:8888  | 双击 bat 或 exe，弹出应用窗口 |
| 依赖     | Python + 浏览器            | Python（或仅 exe）             |
| 打包后   | 无                         | 单 exe，可分发                 |

功能一致：多对话、多模型、技术亮点、API 代理逻辑均相同。
