# OVO 桌面版（独立窗口）

界面仅在 **pywebview 内嵌窗口**中运行（不再提供「只开系统浏览器」模式）。

## 方式一：直接运行（开发 / 日常使用）

1. 安装 **pywebview**（仅首次）：
   ```bash
   pip install pywebview
   ```
   若报错 **Failed building wheel for pythonnet**，可改用：
   ```bash
   pip install pywebview[cef]
   ```
   或运行 **「检查安装.bat」** 末尾按提示安装。
2. 双击 **「启动.bat」** 选 **1**，或在项目目录执行：
   ```bash
   python desktop_app.py
   ```
3. 将弹出标题为 **「OVO」** 的窗口。

使用前请先按需启动 **LiteLLM**（**「启动.bat」** 选 **2**）或 **Ollama**，否则对话会提示无法连接后端。

### 安装 pywebview 报错（pythonnet）时怎么办

| 情况 | 做法 |
|------|------|
| 报错里有 `Failed building wheel for pythonnet` | 先试 **`pip install pywebview[cef]`**；若仍失败，可用 **方式二** 生成 **OVO.exe**，或换 Python 3.11/3.12 后重试。 |

## 方式二：打包成 exe（单文件）

1. 在项目根目录双击 **`build_exe.bat`**（会安装 PyInstaller、pywebview 并执行完整打包参数）。
2. 打包完成后在 **`dist`** 目录得到 **`OVO.exe`**。
3. 可将 **OVO.exe** 复制到任意目录运行；**`api_config.json`**、**`ovo_workspace`** 会写在 exe 同目录。
4. 使用 Docker LiteLLM 时，请将 **`litellm`** 文件夹放在 **OVO.exe** 同目录（或继续使用源码目录下的 **「启动.bat」** 选 **2** 启动容器）。

说明：

- 静态页面与文档已打入 exe；AI 对话仍需本机 **LiteLLM（Docker）** 或 **Ollama**。
- 完整 PyInstaller 参数见项目根目录 **`build_exe.bat`**。

## 与旧版「仅浏览器」的区别

- 不再支持「不装 pywebview、只开 Chrome/Edge」的流程；本地 HTTP 服务仍由 `desktop_app.py` / `OVO.exe` 在后台拉起，仅供内嵌窗口使用。
