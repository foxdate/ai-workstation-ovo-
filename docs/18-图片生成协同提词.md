# 图片生成 · 协同 AI 提词与词条格式

## 协同讨论（多会话）

- 进入 **图片生成** 时，若没有历史讨论，会自动 **新建一条协同讨论**，并向模型注入 **词条格式约定**（界面中有一条〔OVO〕提示气泡；另有一条不展示的「内部」系统说明随每次请求发给 API）。
- 若以前已有讨论，可在 **「协同讨论」** 下拉框中 **切换** 进入以前的对话；点 **「+ 新建讨论」** 会再建一条并 **重新** 注入格式说明。
- 每条讨论独立保存消息与当时选用的协同模型；**清空** 仅删除可见消息，会保留内部格式约定（若需完全重来请新建讨论）。

## 界面行为

- 在「图片生成」页下方 **AI 讨论区** 可选择协同 AI，发送讨论或点击 **「提炼关键词」**。
- 协同 AI 按固定格式输出后，右侧 **「AI 推荐词条」** 会显示为 **可点击的芯片**：
  - **单击**：多选/取消（高亮为已选）。
  - **在词条池内拖动**：调整词条顺序（用于你希望的拼接优先级）。
  - **拖到左侧「使用的提示词」文本框**：在光标处插入该词条（自动补逗号）。
- **应用选中词条**：将当前选中的芯片追加到「使用的提示词」。
- **应用全部推荐**：将全部推荐词条按当前顺序一次性追加。

## AI 必须使用的机器可读格式

为让软件稳定解析，提炼关键词时系统会要求模型使用以下块（标识符需 **完全一致**）：

```
<<<ZHIQUAN_TERMS>>>
pixel art
side view, 2D sprite
角色行走循环
<<<END_ZHIQUAN_TERMS>>>
```

- 每行一个或多个短语；同一行内可用英文逗号或中文逗号分隔。
- 不要使用 `1.`、`2.` 这类编号（解析时会尽量去掉，但可能影响识别）。
- 块 **以外** 可以写给人看的简短说明（可选）。

### 备选：JSON（在代码块内）

````markdown
```json
{ "zhiquan_terms": ["pixel art", "side view", "character walk"] }
```
````

若未检测到上述格式，软件会回退为按换行、逗号等拆分整段回复（效果不如固定格式稳定）。

## 与普通讨论的区别

- **提炼关键词**：强制使用 `<<<ZHIQUAN_TERMS>>>` 块；失败时再按行/逗号拆分。
- **普通发送**：仅当回复里 **出现** 上述块时才会更新词条区，避免把长段闲聊误拆成词条。
